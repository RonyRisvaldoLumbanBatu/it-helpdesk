# Security Policy

## Supported Versions

Kami mendukung versi terbaru dari branch `main`.

| Version | Supported |
|--------|-----------|
| 1.0.x  | ✅ |
| < 1.0  | ❌ |

## Reporting a Vulnerability

Jika Anda menemukan celah keamanan:

1. **Jangan** membuat issue publik
2. Gunakan **GitHub Security Advisories**:
   - https://github.com/RonyRisvaldoLumbanBatu/it-helpdesk/security/advisories
3. Sertakan detail:
   - Langkah reproduksi
   - Dampak potensial
   - Saran mitigasi (jika ada)

Kami akan merespons secepat mungkin.
